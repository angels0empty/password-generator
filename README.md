# Генератор паролей

### Цель: Разработать программу генерации случайного пароля с заданными условиями (длина, кол-во используемых языков, наличие разных регистров, наличие спец символов, наличие определенных цифр).  Произвести расчет необходимого времени для создания паролей с разной длиной и степенью сложности (длины паролей от 10 тыс. до 1 млн. символов).

## 2. Логика генерации

`PasswordGenerator.generate(...)` выполняет следующие действия:

1. Удаляет повторяющиеся цифры через Stream API.
2. Проверяет длину, язык (только если выбраны буквы) и набор цифр.
3. Формирует обязательные группы: выбранные языки, регистры, цифры и спецсимволы.
4. Объединяет группы в общий алфавит через Stream API.
5. Проверяет непустой алфавит и достаточную длину.
6. Добавляет по одному символу из каждой обязательной группы.
7. Заполняет оставшиеся позиции через `IntStream`.
8. Перемешивает результат алгоритмом Фишера-Йетса.

Для рандома спользуется `SecureRandom`. Пароли не записываются в логи.

Поддерживаются:

- английский и русский языки, включая `ё` и `Ё`;
- строчные и прописные буквы;
- пользовательский набор цифр;
- специальные символы;
- длина от 1 до 1 000 000 символов.

## 3. Графический интерфейс

Интерфейс реализован на JavaFX и разделён на два класса.

### `GeneratorView`

Отвечает за:

- ввод параметров;
- фоновую генерацию через `Task`;
- вывод длины и времени;
- копирование в буфер обмена;
- сохранение в файл;
- обработку ошибок без завершения приложения.

Пароли длиной более 100 000 символов не выводятся целиком в текстовое поле, но их можно скопировать или сохранить.

### `BenchmarkView`

Отвечает за:

- запуск бенчмарка;
- отображение таблицы статистики;
- прогресс;
- независимую отмену задачи;
- обработку ошибок записи и выполнения.

## 4. Бенчмарк

`Benchmark` проверяет длины:

```text
10 000, 50 000, 100 000, 250 000, 500 000, 750 000, 1 000 000
```

Профили:

| Профиль | Алфавит |
| --- | --- |
| P1 | Только цифры |
| P2 | Английские строчные буквы |
| P3 | Английские буквы обоих регистров и цифры |
| P4 | Английские и русские буквы обоих регистров, цифры |
| P5 | Все перечисленные символы и спецсимволы |

Для каждой комбинации выполняется один прогрев и 10 измерений. Всего 35 серий и 350 запусков. Число профилей и повторов задано константами `Benchmark.PROFILES` и `Benchmark.REPEATS`.

Время измеряется через `System.nanoTime()` только вокруг генерации. Вывод и запись файлов в замер не входят.

Для каждой серии рассчитываются минимум, максимум, среднее, медиана и скорость в символах в секунду. Суммирование времени выполняется через `Arrays.stream(...)`.

## 5. Результаты работы

- `benchmark.csv` - длина, профиль, номер и время каждого запуска.
- `benchmark-summary.csv` - итоговая статистика по серии.
- `system-info.txt` - CPU, число логических процессоров, RAM, ОС и Java.
- `logs/app.log` - логи запуска, генерации, бенчмарка и ошибок.

Сведения о системе собираются библиотекой OSHI: ОС, производитель и модель, процессор, число логических процессоров, объём RAM и версия Java.

## 6. Сборка и запуск

Для сборки нужен JDK 17, для запуска готового JAR - Java 17 или новее. 
Команды ниже написаны в едином виде для PowerShell и Unix-оболочек (Linux/macOS/etc): `./gradlew`. На Linux/macOS при необходимости предварительно выдаются права на запуск (`chmod +x gradlew`), в старом CMD/PowerShell при ошибке можно использовать `.\gradlew` или `gradlew.bat`.

### Windows
Ввиду того, что в проекте все заточено под UTF-8 - могут быть проблемы с отображением кириллицы.
Если таковы возникнут - рекомендуется поменять кодировку:
```bat
chcp 65001
```
На работу программы это не влияет (может быть неправильное отображение кириллицы в логе)

### Полная сборка

```bash
./gradlew clean build
```

Команда компилирует проект, запускает JUnit-тесты и создаёт fat JAR `password-generator.jar`.

### Графический интерфейс из JAR

```bash
java -jar password-generator.jar
```

### Консольная генерация

```bash
java -jar password-generator.jar console
```

### Полный бенчмарк

```bash
java -jar password-generator.jar test
```

Ход серий выводится через лог. При любом другом аргументе выводится подсказка `[-] Аргументы: console | test`.

### JUnit-тесты

```bash
./gradlew test
```

В проекте 26 тест-кейсов в 12 тест-методах. Используются параметризованные тесты (`@ValueSource`, `@CsvSource`, `@MethodSource`) и AssertJ. Проверяются алфавиты, обязательные группы, ошибки настроек, миллион символов, статистика, CSV, сведения о системе и отмена.

### JavaDoc

```bash
./gradlew javadoc
```

Документация генерируется для public и private методов. Документация находится в `docs/javadoc/index.html`.
