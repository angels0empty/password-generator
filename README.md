# Генератор паролей

## Разработка генератора паролей по заданным параметрам  
### Разработать программу генерации случайного пароля с задаными условиями (длина, кол-во используемых языков, наличие разных регистров, наличие спец символов, наличие определенных цифр).  Произвести расчет  времени необхдимого времени для создания паролей с разной длинной и степенью сложности (Длинны паролей от 10 тыс. до 1 млн. симвалов).
